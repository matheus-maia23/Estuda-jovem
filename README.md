# Estuda Jovem — versão ampliada

Plataforma educacional estática feita com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server do VS Code.
3. Não há etapa de instalação nem dependências obrigatórias.

## O que já está implementado
- Dashboard inicial.
- Catálogo com 29 disciplinas nas quatro áreas do conhecimento (Linguagens, Matemática, Natureza e Humanas).
- 104 aulas/tópicos com explicações, exemplos, orientação de leitura de prova e roteiro de revisão.
- Blog com 104 aulas e artigos vinculados às disciplinas e aos tópicos do catálogo.
- Busca e filtros no Blog.
- Favoritos e leitura concluída via `localStorage`.
- Banco com 203 questões autorais de prática, distribuídas pelas 29 disciplinas, com alternativas e explicações.
- Cronograma pessoal que cria uma trilha individual por sessão, reunindo aulas e questões da disciplina escolhida.
- Painel simples de desempenho.
- Layout responsivo e modo foco.

## Limitações importantes
- É um protótipo front-end: os dados ficam no navegador e não são sincronizados entre dispositivos.
- Não há cadastro real, autenticação, banco de dados ou painel administrativo.
- As 203 questões são autorais para prática e não devem ser apresentadas como questões oficiais ou retiradas de provas anteriores. O conteúdo é uma base didática introdutória, não substitui editais, livros, aulas e materiais oficiais; recomenda-se revisão pedagógica antes de publicação.
- Antes de publicar, revise os conteúdos, acrescente fontes bibliográficas e valide acessibilidade e funcionamento em diferentes navegadores.

## Próximas evoluções recomendadas
1. Validar os conteúdos com professores e revisar a qualidade pedagógica de cada aula e questão.
2. Aprofundar os tópicos com exercícios resolvidos, fontes bibliográficas e materiais complementares.
3. Acrescentar questões oficiais apenas quando houver fonte e permissão de uso verificadas.
4. Implementar backend e banco de dados para contas e sincronização.
5. Integrar videoaulas de fontes confiáveis e verificar disponibilidade dos links.
